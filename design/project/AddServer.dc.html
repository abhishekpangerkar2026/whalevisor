Join code

WHALE-7K2M-9QXD
Valid for 30 minutes, for one server.
  1. Boot the new server from the WhaleVisor ISO.
  2. At "Network and cluster", choose "Join an existing cluster".
  3. Enter this code. The server joins and copies the cluster's settings.

Before it can join

  • Same WhaleVisor version as the cluster (1.0)
  • Processor from the same maker as the other servers, so running VMs can move to it
  • Reachable on the management, storage and migration networks
  • Clock in sync with the cluster
This cluster is certified for up to 16 servers. For more, create a second cluster and manage both from WhaleVisor Manager.
