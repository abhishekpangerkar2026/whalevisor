Welcome to WhaleVisor

WhaleVisor turns this server into a host for virtual machines. It runs directly on the hardware, keeps every virtual machine isolated from the others, and is managed from a web browser, with Whale AI to forecast capacity and help you operate it.

What you can run

Linux and Windows Server virtual machines, including GPU workloads.

What this installer does

Checks the hardware, installs WhaleVisor on a disk you choose, and sets up the network. About 10 minutes.

What to have ready

An IP address for this server, the gateway address, and an administrator password.
Nothing on this server is changed until you confirm the install disk. Version 1.0 · build 2026.11 · BlueWhale Stack
