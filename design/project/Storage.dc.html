Connecting external storage

  1. On the storage array, allow this cluster's servers to connect.
  2. Choose Add datastore and pick the type: NFS, iSCSI, Fibre Channel or NVMe over network.
  3. WhaleVisor connects every server, tests the paths and makes the storage available to VMs.
Every server keeps two paths to block storage, so one cable or switch failure does not interrupt VMs.
